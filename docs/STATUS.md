## Zum Ausprobieren

Hier tragen Agenten alles ein, was Jan selbst testen kann, mit Pfad und kurzer Anleitung.

- **Partie gegen 3 Bots (Grundgerüst)** (seit 2026-11-12, C1): Quellcode `apps/client`. Noch nicht online (Veröffentlichung unter `docs/play/` kommt mit C7); lokal mit `npm ci` und `npm run dev:client` starten und die angezeigte Adresse öffnen, z. B. http://localhost:5173/?seed=3. Die Seite startet eine Partie gegen 3 GreedyBots und zeigt den ganzen Zustand als Text (Leben, Macht, Schatzkammer, Anführer, eigene Hand, Einheiten je Zone, Kämpfe der letzten Runde, Spielende) und darüber das 3D-Brett (seit C2a, 2026-11-13): Mitte und die Frontarenen zwischen den Sitzen als Hexfelder, jede Zone in der Farbe ihres Besitzers, an jeder Sitz-Ecke eine Säule (Höhe = Leben) mit den drei Reserve-Plätzen; Kamera schaut aus deiner Ecke, Ziehen dreht, Mausrad oder zwei Finger zoomen. Einheiten auf dem Brett kommen mit C2b. Ohne Starten ansehen: Vorschaubild `docs/bilder/c2a-brett.png`. Eigene Züge gibt es erst mit C3: „Runde auslassen“ reicht eine leere Planung ein, „Autopilot“ lässt einen Bot für dich planen, „Autopilot bis zum Ende“ spielt die Partie fertig. Seed oben ändern und „Neue Partie“ für eine andere Partie.
- **Kampf-Sandbox** (seit 2026-10-31): https://janpatrickschmidt.github.io/StrategyGameTest/play/sandbox.html (Datei `docs/play/sandbox.html`, Quellcode `apps/sandbox`). Läuft im Browser, auch am Handy, ohne Server. Einheit und Sterne oben wählen, auf ein Feld tippen (obere drei Reihen = Seite A blau, untere drei = Seite B rot), „Kampf starten“, dann abspielen oder Tick für Tick weiterschalten. Am Ende stehen Sieger, Überlebende und Durchbruch-Schaden; die Runde für den Grundschaden ist einstellbar. „A → B spiegeln“ kopiert eine Aufstellung auf die Gegenseite, „Link kopieren“ speichert die Aufstellung im Link (gut für Feedback zu einem konkreten Fall). Seit 2026-10-31 (E10a) wirken die Fähigkeiten im Kampf (z. B. Kesselflicker ruft einen Goblin, Bannerträger stärkt, Donnerbüchse trifft mehrere, Mondpriesterin schützt, Anführer-Mana-Fähigkeiten); das Protokoll zeigt sie mit ✦. Noch nicht: Wirkungen über den Kampf hinaus (Gold, Anführer-XP, Flüche) und Zauber (E10b, E11); die Rassen-Resonanz (E10c1) wirkt in der Engine, in der Sandbox aber noch nicht, weil die Sandbox nur eine Arena und kein ganzes Brett kennt. Seit 2026-11-01 (P2) skalieren Fähigkeitsschaden und Schilde mit dem Stern (z. B. Lehrling ★3: 6 statt 2 Schaden, Mondpriesterin ★3: 19 Schild). Hinweis: GitHub Pages braucht nach dem Push ein bis zwei Minuten.
- **Simulations-Werkzeug** (seit 2026-11-10, E15): Quellcode `tools/sim`. Spielt viele Partien mit Bots und schreibt eine CSV (eine Zeile je Partie und Spieler: Seed, Anführer, Bot, Platz, Sieger, Siegart, Runden, Leben, Machtpunkte, Käufe gesamt und je Karte). Ohne Programmieren ansehen: Beispiel mit 100 GreedyBot-Partien `docs/sim/beispiel-greedy-100.csv` (auf GitHub als Tabelle sichtbar, in Excel/Numbers/Google Tabellen importierbar). Selbst starten (Node 20+, im Repository): `npm ci`, dann `npm run sim -- --games 100`; Optionen `--seed 1`, `--bots greedy,random,random,random` (ein Bot je Platz oder einer für alle), `--leaders random|rotate|brann,ilyra,vex,morgra`, `--no-rotate-bots`, `--out datei.csv` (`-` = Konsole). Die Konsole zeigt eine Zusammenfassung (Runden, Siegarten, Siegquote je Anführer und Bot). 100 Partien dauern etwa 2 Sekunden. Seit 2026-11-10 (E16a): `--check` prüft zusätzlich jede Partie (keine Ausnahme, Ende innerhalb des Rundenlimits, keine abgelehnten Aktionen, gültige Plätze) und meldet „Abnahme: BESTANDEN“ oder die Befunde; `npm run accept:m2` ist der Abnahme-Lauf mit 1.000 GreedyBot-Partien (etwa 30 Sekunden, CSV nach `sim-output/abnahme-m2.csv`).
- **Spec-Abgleich** (seit 2026-11-10, E16b): `npm run check:spec` zeigt, welche Regeln der Spec (`docs/spec/regeln-prototyp.md`) noch keinen Test mit ihrer Kennung haben; `npm run check:spec -- --table datei.md` schreibt zusätzlich eine Tabelle aller Regeln mit Testzahl. Ohne Programmieren: der aktuelle Bericht liegt in `docs/berichte/spec-abgleich-2026-11-10.md`.
